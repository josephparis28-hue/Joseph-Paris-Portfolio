My Dev Tools Vandalism: Nasa.gov

Home

I used browser developer tools to temporarily "vandalize" the NASA.gov homepage. This page documents my DevTools Vandalism exercise for CMPA‑3304. The goal was to explore how browser developer tools allow real‑time manipulation of HTML and CSS.

Figure 1: Modified NASA homepage HTML headline using DevTools.

What I "Vandalized"

For this exercise, I modified the main headline on NASA.gov by changing it to: “Exploring the Universe… and Losing Our Keys in Space.” I also edited the navigation text and experimented with several CSS properties.

In the Styles panel, I changed the headline color to bright pink, increased the font size, added a blue background, and applied a lime dashed border. These dramatic changes helped me understand how HTML and CSS work together and how DevTools can be used to inspect, test, and manipulate webpage elements during development.

Figure 2: Modified NASA homepage CSS style using DevTools.

This exercise helped me understand how HTML structure and CSS rules interact. Seeing changes in real time made the relationship between markup and styling much clearer, and I feel more confident debugging layout issues in my own projects.
