# **Analyzing an Organizing System: The Smithsonian Online Collection**

**Website:** `https://collections.si.edu/` [Smithsonian Collections Online](https://collections.si.edu/search/)

## **Overview**

The Smithsonian Online Collection is a large public digital collection that provides access to millions of artifacts, artworks, archival materials and scientific specimens. Its organizing system is designed to support research, browsing, discovery and public education. This analysis examines the system’s resources, interactions, classification methods and representation of relationships.

### 1. Primary Resources Being Organized

The primary resources in the Smithsonian Online Collection are **digital representations of physical artifacts** held across Smithsonian museums and research centers. These include:

- Historical objects (e.g., Lincoln’s top hat, Apollo 11 mission artifacts)
- Artworks (paintings, sculptures, photography)
- Natural history specimens (minerals, fossils, biological samples)
- Archival materials (letters, manuscripts, maps)
- Cultural objects (textiles, tools, ceremonial items)

Each resource is represented through metadata, high‑resolution images, descriptions, provenance information and museum location. The system organizes both **digital metadata** and **physical object information**, making it a hybrid organizing system.

### 2. Primary Interactions Supported

The Smithsonian system supports several key interactions:

#### Research

Users can perform targeted searches using filters such as object type, date, museum, material or topic. Scholars and students rely on this for academic research.

#### Browsing

Users can explore collections by museum, theme or category (e.g., “Air and Space,” “African American History,” “Invention and Technology”). This supports casual exploration and learning.

#### Fact‑Checking

Because the Smithsonian is authoritative, users often verify historical details, dates or object provenance.

#### Discovery

The interface encourages discovery through related items, thematic collections and curated exhibits. Users often encounter resources they were not actively searching for.

These interactions align with Glushko’s modes of **search, browse and discovery** which demonstrates a well‑designed organizing system.

### 3. Classification System Used

The Smithsonian uses a **faceted classification system** combined with hierarchical elements.

#### Faceted Classification

Users can filter resources by:

- Object type
- Topic
- Date
- Museum
- Material
- Culture
- Place
- Physical characteristics

This allows multiple entry points into the collection and supports diverse user goals.

#### Hierarchical Classification

Some categories are structured hierarchically, such as:

- Museum → Collection → Object
- Topic → Subtopic → Item

#### Effectiveness

This hybrid system is highly effective for its audience, which ranges from casual visitors to researchers. Facets support flexible exploration, while hierarchies provide structure for users who prefer organized pathways.

### 4. Representation of Relationships Between Resources

Relationships are represented through:

#### Hyperlinks

Objects link to related artifacts, museum pages and thematic collections.

#### Categories and Tags

Items are grouped by topic, material, culture and museum that creates conceptual relationships.

#### “Related Items” Sections

Algorithmic recommendations show visually similar or contextually connected objects.

#### Curated Collections

Human‑curated exhibits create narrative relationships between resources.

#### Metadata Connections

Shared metadata fields (e.g., “Culture: Navajo”) connect items across museums.

These relationship structures support discovery, contextual understanding and deeper exploration.
